# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in Anigma, please report it privately by email:

**anigmamodern@gmail.com**

Please do not publish exploitable details in a public issue or discussion before the maintainer has had a reasonable opportunity to investigate and prepare a fix.

When reporting, include:
- The affected Anigma version and platform.
- A clear description of the issue and its potential impact.
- Reproduction steps or a proof of concept, if safe to share.
- Any relevant logs or screenshots, after removing passwords, private keys, personal information, and other sensitive data.
- A way to contact you if clarification is needed.

## Responsible disclosure

Please test only on systems and data you own or have explicit permission to assess. Do not access, alter, or disclose other people's data. The project does not promise a response time or a bug bounty.

We appreciate responsible reports that help improve Anigma's security.
